# Portfolio — Manohar Kharvi

Personal portfolio. Single page, dark/light, no CMS — all content lives in
[`src/lib/data.ts`](src/lib/data.ts).

## Stack

Next.js 16 (App Router) · TypeScript · Tailwind v4 · shadcn/ui · next-themes

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
